# Mirante Watch Face Store

Watch faces published from **Mirante** (the macOS/iOS editor for the Xiaomi
pop-up band watch face). The app writes `faces/<publisher>/<slug>/`
directories containing `face.fprj`, `metadata.json` and `preview.png`; the
GitHub Actions workflow compiles each `.fprj` into `face.bin` on the Windows
toolchain and regenerates the root `index.json` for discovery.

The store is a flat static catalog, in the same spirit as
`ipetinate/phantom-extensions`: any client can read `index.json` and render
faces directly from their folders.

## Layout
- `faces/<publisher>/<slug>/` — one folder per publication.
  - `face.fprj` — the source project (written by Mirante).
  - `face.bin` — compiled binary produced by the CI (Windows toolchain).
  - `metadata.json` — `StoreFace` record (name, description, tags, ...).
  - `preview.png` — render used as the store thumbnail.
- `index.json` — regenerated by `.github/scripts/rebuild_index.py`.

## Publishing
1. Finish a face in Mirante and hit **Publish to Store**.
2. The app authenticates (GitHub token or anonymous) and commits the folder.
3. CI builds `face.bin` and updates `index.json`; on the next store read the
   face shows up with the compiling badge cleared.
